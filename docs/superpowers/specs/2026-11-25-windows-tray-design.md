# Windows 시스템 트레이 설계

## 목표

`statusline.exe tray`를 실행하면 Windows 시스템 트레이에 선택한 provider의 잔여율이 표시된다. macOS와 동일한 통합 캐시, 요약 규칙, 메뉴 동작을 사용한다. macOS 메뉴 막대는 기존 텍스트 표시를 유지한다.

## 검토한 접근 방식

1. **숫자 아이콘 하나와 전체 요약 툴팁 (선택)** — 기본 잔여율을 한눈에 확인할 수 있고 기존 `fyne.io/systray`와 공통 메뉴를 재사용한다.
2. **숫자 아이콘 두 개** — z.ai의 5시간·주간 잔여율을 동시에 표시할 수 있다. 트레이 슬롯 두 개와 다중 아이콘 관리 코드가 필요하다.
3. **고정 아이콘과 전체 요약 툴팁** — 구현 범위가 가장 작다. 숫자를 확인할 때 마우스를 올려야 한다.

## 표시와 동작

| 메인 provider와 캐시 상태 | Windows 아이콘 | Windows 툴팁 |
| --- | --- | --- |
| z.ai 5시간 87%, 주간 45% | `87` | `z87 w45` |
| ChatGPT 잔여율 48% | `48` | `c48` |
| z.ai 캐시 또는 ChatGPT rate 정보 없음 | `–` | 기존 요약 `…` 또는 `c-` |

아이콘에는 `0`부터 `100`까지 정수 전체를 표시한다. `100`과 `–`도 일반 Windows 트레이 크기에서 읽을 수 있도록 대비가 높은 배경과 숫자를 사용한다. 아이콘에 적용할 색상과 서체는 구현 시 실제 트레이에서 가독성을 기준으로 정한다. 아이콘이 숨겨진 영역에 있으면 작업 표시줄에서 표시 여부를 사용자가 설정할 수 있다.

우클릭 메뉴에서 기존 provider별 상세, 메인 provider 전환, 즉시 수집, 종료를 제공한다. 메인 provider 설정 저장과 캐시 갱신 동작은 기존 경로를 사용한다. 자동 시작과 별도 팝업 창은 이 변경의 범위 밖이다.

## 구현 경계

- Windows 전용 아이콘 렌더링 경로를 추가하고 기존 `tray.Title`에서 산출한 요약을 재사용한다. 잔여율 반올림과 누락 판정은 공통 렌더링에 맡긴다.
- 기존 `systray.SetIcon`에 전달할 ICO를 16×16 및 32×32 이미지로 구성한다. 숫자 범위와 누락 표시를 합쳐 고유 아이콘을 최대 102개로 제한한다. 현재 표시값이 바뀔 때만 아이콘을 적용한다. 주간 값만 바뀌면 툴팁을 갱신한다.
- 기존 `statusline tray` 명령, 5초 폴링, 캐시 TTL, 중복 수집 방지 방식을 사용한다. 별도 의존성 없이 구현한다.
- 사용 가이드와 로드맵은 Windows 검증 결과에 맞춰 갱신한다.

## 검증

- 자동 테스트에서 z.ai와 ChatGPT 요약, `0`·`100`·누락 상태, 16×16 및 32×32 ICO 구조를 확인한다. `go test ./...`와 Windows 빌드를 실행한다.
- Windows에서 트레이 등록, 숫자 가독성, 툴팁, 우클릭 메뉴, provider 전환·저장, 수동 갱신, 종료를 확인한다. 실행 환경 제약으로 실측할 수 없는 항목은 검증 결과에 기록한다.
