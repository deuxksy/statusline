# statusline 문서 허브 (Documentation Hub)

이 디렉토리는 `statusline` 프로젝트의 기술 문서 및 가이드를 관리합니다.

## 📁 하위 디렉토리 역할

- **[`okf/`](./okf/README.md)**: [Diátaxis Framework](https://diataxis.fr/)의 4분면 체계에 따라 정리된 Open Knowledge Framework 개발자 문서.
- **[`samples/`](./samples/README.md)**: AI CLI 호스트(`antigravity`, `claude`, `codex`)에서 수집한 실체 STDIN JSON 입력 샘플 파일 및 테스트 방법.
- **`superpowers/`**: 내부 AI 에이전트 전용 구현 스펙 및 개발 계획 문서 (일반 사용자 인덱스 제외 대상).
